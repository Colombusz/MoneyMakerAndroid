# MoneyMaker Android

React Native mobile app for budget tracking with partner co-budgeting. Works offline and syncs when online.

## Features

- **Offline-first** — Track expenses anytime, syncs automatically when connection restores
- **Partner co-budgeting** — Shared budgets with real-time collaboration
- **Cross-platform** — iOS and Android via Expo
- **Secure sync** — Encrypted data transfer with conflict resolution

## Tech Stack

- Expo / React Native
- TypeScript
- React Navigation
- Redux Toolkit
